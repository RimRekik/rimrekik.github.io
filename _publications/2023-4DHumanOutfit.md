## Summary
4DHumanOutfit is a dataset of **densely sampled 4D human motion sequences** captured on the Kinovis multi-camera platform. Several actors each wear several outfits and perform several motions in each outfit, so the data forms a **cube along three axes: identity, outfit and motion**. The dataset provides multi-view images, 4D reconstructions and reference solutions along each axis, with baseline results showing how they support evaluation. It targets augmented reality, avatar creation and virtual try-on.

The 4D reconstructions of this dataset are the reference animations of my perceptual study [4DHumanPercept (IEEE TVCG 2025)](/publications/2025-QualityAssessment-TVCG/).
